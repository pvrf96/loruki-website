# RULES — o que a IA deve e NUNCA deve fazer

## Sempre
- Toda informação factual (prazo, requisito, bolsa, diretriz) tem `fonte_url` e `verificado_em`.
- Se não houver fonte, o campo fica "sem informação" — nunca preencher por suposição.
- Diretrizes: resumir com palavras próprias e citar (sociedade, ano, classe/nível). Nada de copiar trechos.
- Português do Brasil, linguagem de colega para colega.
- Passos pequenos: uma tarefa do TASKS.md por vez, mostrar o resultado, esperar aprovação.

## Nunca
- Inventar programa, valor de bolsa, prazo ou requisito.
- Usar imagem com direito autoral (atlas comercial, logos de instituições sem permissão).
- Prometer vaga, aprovação ou visto.
- Expor dados pessoais de residentes/relatos sem autorização.
- Misturar com material de prova (outro produto).
